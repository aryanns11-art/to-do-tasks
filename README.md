# 📝 To-Do List App (Python CLI)

A simple command-line To-Do List application built using Python.  
It allows users to **add, view, and delete tasks**, with data stored persistently in a text file.

---

## 🚀 Features

- 📋 View all tasks  
- ➕ Add new tasks  
- ❌ Delete tasks by index  
- 💾 Persistent storage using `tasks.txt`  
- 🔄 Auto-save on every change  
- 🖥️ Simple CLI-based interface  

---

## 🛠️ Technologies Used

- Python 3  
- File Handling (`os` module)  
- Command Line Interface (CLI)
